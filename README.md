Team Reflections — Hackathon Journey
GS
Gayathri (@gsrini3)
Hackathon Journey Reflection

1. What inspired your team to choose this project?
We were inspired by the growing momentum of NASA's Commercial Lunar Payload Services (CLPS) program and the exciting prospect of sustained human and robotic exploration of the Moon. We wanted to build something that went beyond simply displaying mission information. Our vision was to create an interactive lunar landing-site navigator that brings together mission data, 3D lunar visualization, terrain analysis, and environmental factors such as sunlight availability and Earth visibility. We wanted to make complex lunar mission information easier to explore while addressing challenges that future lunar missions may encounter.

2. What did your team learn during the hackathon?
We gained valuable experience combining geospatial data processing, scientific computing, and modern web technologies into one application. We learned how NASA's LOLA elevation datasets can be processed into terrain profiles and 360-degree horizon information, and how JPL Horizons data can help analyze Sun and Earth positions relative to lunar landing sites. We also learned the importance of lunar-specific coordinate transformations, integrating multiple data sources, and designing interactive 3D visualizations that make complex scientific information accessible.

3. What roadblocks did your team encounter, and how did you overcome them?
One of our biggest challenges was bringing together large NASA lunar elevation datasets, external REST APIs, and astronomical calculations into a unified application. LOLA elevation datasets have different resolutions and geographic coverage, and some files are several gigabytes in size. We addressed this by developing a dedicated Python terrain-processing engine using Rasterio, NumPy, and PyProj to process site-specific elevation data and generate 360-degree terrain horizon profiles, which we integrated into the application for terrain-aware analysis.

Another challenge was integrating NASA/JPL Horizons through its REST API to retrieve accurate Sun and Earth positions relative to specific lunar landing coordinates. We had to handle API query construction, response parsing, coordinate reference frames, request timeouts, and the processing of time-series data. We also explored NASA's NAIF SPICE toolkit through SpiceyPy, which requires the appropriate planetary and lunar kernels to calculate celestial positions locally. Supporting both approaches helped us build flexibility into our ephemeris engine, with an analytical synthetic fallback for testing when live API access or SPICE kernels were unavailable.

We also faced challenges in connecting scientific computations with the interactive 3D visualization and ensuring that lunar-specific coordinate transformations and terrain calculations were consistent across components. By breaking the system into modular engines, validating calculations independently, and integrating the components incrementally, we overcame these challenges and developed a comprehensive lunar landing-site analysis platform.
